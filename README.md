
# 🤖 JigyasaAI – AI-Powered Q&A Assistant

JigyasaAI is an AI-powered Question & Answer chatbot developed using **Python, Streamlit, LangChain, and Google Gemini**. It is designed to help students and learners understand concepts through simple explanations, practical examples, and an interactive chat interface.

The chatbot focuses on making learning easier by providing beginner-friendly answers, Hinglish examples, quick summaries, and memorable learning tricks.

## 🌐 Live Demo

**Try JigyasaAI here:** [Live Application]([https://jigyasaai-q-n-bot-kbut6qdjt6gbszcjdrvzjq.streamlit.app/])


## ✨ Features

- **AI-Powered Responses:** Uses Google Gemini to generate intelligent and context-aware answers.
- **Simple Explanations:** Explains concepts in beginner-friendly English.
- **Hinglish Examples:** Uses relatable Hindi + English examples to improve understanding.
- **Conversation Memory:** Maintains chat history during the active session.
- **Quick Summary:** Concludes answers with two short summary points.
- **Memory Tricks:** Provides memorable Hindi/Hinglish words to help recall concepts.
- **Interactive Chat Interface:** Built with Streamlit for a simple and user-friendly experience.
- **Reset Conversation:** Allows users to clear the current chat and start again.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Core programming language |

| Google Gemini | AI language model |
| StrOutputParser | Converts model responses into plain text |
| python-dotenv | Environment variable management |

## ⚙️ How It Works

1. The user enters a question through the Streamlit chat interface.
2. The question is added to the conversation history.
3. LangChain sends the conversation context to Google Gemini.
4. Gemini generates a response based on the system instructions and conversation.
5. The response is converted into plain text using `StrOutputParser`.
6. The conversation is displayed and maintained using Streamlit session state.
